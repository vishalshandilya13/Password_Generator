# Password Generator

A small Python program that creates a password using a requested length and a mix of character types.

## Features

- Choose the password length
- Include uppercase and lowercase letters, digits, and special characters

## Run

Requires Python 3. Run from the project folder:

```bash
python PasswordGenerator.py
```

Follow the prompts to enter the desired password length.

## Project file

- `PasswordGenerator.py` — password generation script.
